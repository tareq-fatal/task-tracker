Task Tracker — installation on your own server

Installer file task-tracker-onprem-1.2.0.run · works without any internet · Ubuntu 22.04 / 24.04

1 What you need

MinimumRecommended
Processor2 cores (x86_64)4 cores
Memory4 GB8 GB
Disk20 GB free50 GB SSD
SystemUbuntu 22.04 or 24.04, access with sudo
Networkports 80 and 443 free; fixed LAN IP recommended

Docker is installed automatically (offline from the package). Data never leaves the server — no cloud, no access from outside.

2 Installation step by step (no internet)

  1. 1Copy and check the file

    Plug in the USB stick, copy task-tracker-onprem-1.2.0.run (and .sha256) to the server; the check must report “OK”:

    cp /media/$USER/USB/task-tracker-onprem-1.2.0.run* ~/ && cd ~
sha256sum -c task-tracker-onprem-1.2.0.run.sha256
  2. 2Start the installation

    One command, then four questions — Enter keeps the suggestion: name of the interface, logo (optional, path to PNG/JPG/WEBP/SVG), language (ar, de, en), address (host name optional, IP is detected).

    sudo bash task-tracker-onprem-1.2.0.run
  3. 3Wait (3–5 minutes)

    At the end the installer shows the address, user name, invite link and the path + fingerprint of the certificate. Everything is also in /opt/task-tracker/ACCESS.txt (root only): sudo cat /opt/task-tracker/ACCESS.txt

  4. 4Import the certificate — once per device

    The server issues its own HTTPS certificates. For browsers to trust it, import /opt/task-tracker/ca/task-tracker-root-ca.crt (or download http://<server-IP>/ca.crt) and compare the fingerprint:

    WindowsDouble-click the file → Install Certificate → Local Machine → “Place all certificates in the following store” → Trusted Root Certification Authorities.
    AndroidSettings → Security → Encryption & credentials → Install a certificate → CA certificate.
    iPhone/iPadOpen the download link in Safari → Settings → install the profile; then General → About → Certificate Trust Settings → switch on.
  5. 5Open the invite link

    Open the link in the browser and choose a password — done, you are logged in as superuser. The link works once only and for 72 hours. Expired? sudo /opt/task-tracker/invite.sh creates a new one.

Without questions: sudo bash task-tracker-onprem-1.2.0.run -- --app-name "My Team" --locale en --yes. With internet and your own domain (online package): sudo ./install.sh --tls domain --domain tasks.example.com.

3 Firewall / ports (all inbound, TCP)

443 (HTTPS)Default “internal” and “domain”: from the LAN (with “domain”: from the internet). Not needed for “http”.
80 (HTTP)Redirect to HTTPS, certificate /ca.crt; the only port for “http”; with “domain” required from the internet.
Never openPostgreSQL (5432), app (3000) — internal Docker network only. Outbound: nothing (except “domain”).

Other ports: --http-port 8080 --https-port 8443. Docker bypasses UFW — restrict with the firewall in front or the DOCKER-USER chain.

4 Name, logo, language

NameQuestion 1 of the installation. Change it later: APP_NAME=… in /opt/task-tracker/.env, then sudo ./update.sh --restart. Empty = default name per language.
Logo, coloursLogo: question 2 (max. 2 MB). Later in the app as superuser: Settings → Branding. Included in backups.
LanguageQuestion 3 — language of the login page and of the superuser. Every user can switch their own language.

Run all commands in the folder /opt/task-tracker: cd /opt/task-tracker

5 Backup

automaticevery night at 03:30, the last 14 are kept in /var/backups/task-tracker
sudo ./backup.shmake a backup now
sudo ./backup.sh --to /media/$USER/USBwrite the backup straight to a USB stick

Copy to USB regularly (a backup on the failed server is gone too). Not encrypted, contains every password: keep it safe.

6 Restore

sudo ./restore.shlist the available backups
sudo ./restore.sh --from latest --yesrestore the newest backup
sudo ./restore.sh --from /media/$USER/USB/20261031-033000 --yesrestore a backup from a USB stick

The current state is saved first (pre-restore-…) — can be undone.

7 Update and rollback

sudo bash task-tracker-onprem-<new>.runnew version: detects the installation and offers the update
sudo ./update.sh --rollbackundo the last update
sudo ./update.sh --restartrestart only (e.g. after editing .env)

Every update backs up everything first. If the new version does not start cleanly, the old one runs again automatically.

8 If something does not work

Certificate warningCertificate not imported on that device yet (step 4) — or an address was opened other than the one given at installation.
Site not reachablesudo docker compose ps — all three services “running”, app “healthy”. Log: sudo docker compose logs -f app
Link expired / password forgottensudo ./invite.sh (for other users: --user NAME)
“Checksum MISMATCH”The .run file is damaged — copy it again.
