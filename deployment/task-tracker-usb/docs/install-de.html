Task Tracker — Installation auf dem eigenen Server

Installationsdatei task-tracker-onprem-1.2.0.run · auch ganz ohne Internet · Ubuntu 22.04 / 24.04

1 Was Sie brauchen

MindestensEmpfohlen
Prozessor2 Kerne (x86_64 oder ARM64)4 Kerne
Arbeitsspeicher4 GB8 GB
Festplatte20 GB frei50 GB SSD
SystemUbuntu 22.04 oder 24.04, Zugang mit sudo
NetzwerkPorts 80 und 443 frei; feste LAN-IP empfohlen

Docker wird automatisch installiert (offline aus dem Paket). Daten verlassen den Server nicht — keine Cloud, kein Zugang von außen.

2 Installation Schritt für Schritt (ohne Internet)

  1. 1Datei kopieren und prüfen

    USB-Stick anschließen, die Datei task-tracker-onprem-1.2.0.run (und .sha256) auf den Server kopieren; die Prüfung muss „OK“ melden:

    cp /media/$USER/USB/task-tracker-onprem-1.2.0.run* ~/ && cd ~
sha256sum -c task-tracker-onprem-1.2.0.run.sha256
  2. 2Installation starten

    Ein Befehl, dann vier Fragen — Enter übernimmt den Vorschlag: Name der Oberfläche, Logo (optional, Pfad zu PNG/JPG/WEBP/SVG), Sprache (ar, de, en), Adresse (Hostname optional, IP wird erkannt).

    sudo bash task-tracker-onprem-1.2.0.run
  3. 3Warten (3–5 Minuten)

    Am Ende zeigt der Installer Adresse, Benutzername, Einladungslink und Pfad + Fingerabdruck des Zertifikats. Alles steht auch in /opt/task-tracker/ACCESS.txt (nur root): sudo cat /opt/task-tracker/ACCESS.txt

  4. 4Zertifikat importieren — einmal je Gerät

    Der Server stellt seine HTTPS-Zertifikate selbst aus. Damit Browser ihm vertrauen, die Datei /opt/task-tracker/ca/task-tracker-root-ca.crt (oder Download http://<Server-IP>/ca.crt) importieren und den Fingerabdruck vergleichen:

    WindowsDatei doppelklicken → Zertifikat installieren → Lokaler Computer → „Alle Zertifikate in folgendem Speicher“ → Vertrauenswürdige Stammzertifizierungsstellen.
    AndroidEinstellungen → Sicherheit → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat.
    iPhone/iPadDownload-Link in Safari öffnen → Einstellungen → Profil installieren; dann Allgemein → Info → Zertifikatsvertrauenseinstellungen → einschalten.
  5. 5Einladungslink öffnen

    Link im Browser öffnen, Passwort wählen — fertig, Sie sind als Superuser angemeldet. Der Link gilt nur einmal und 72 Stunden. Abgelaufen? sudo /opt/task-tracker/invite.sh erzeugt einen neuen.

Ohne Fragen: sudo bash task-tracker-onprem-1.2.0.run -- --app-name "Mein Team" --locale de --yes. Mit Internet und eigener Domain (Online-Paket): sudo ./install.sh --tls domain --domain tasks.firma.de.

3 Name, Logo, Sprache

NameFrage 1 bei der Installation. Später ändern: APP_NAME=… in /opt/task-tracker/.env, dann sudo ./update.sh --restart. Leer = Standardname je Sprache.
Logo, FarbenLogo: Frage 2 (max. 2 MB). Später in der App als Superuser: Einstellungen → Branding. Wird mitgesichert.
SpracheFrage 3 — Sprache der Anmeldeseite und des Superusers. Jeder Benutzer kann seine Sprache selbst umstellen.

Alle Befehle im Ordner /opt/task-tracker ausführen: cd /opt/task-tracker

4 Sicherung (Backup)

automatischjede Nacht um 03:30, die letzten 14 bleiben in /var/backups/task-tracker
sudo ./backup.shsofort eine Sicherung erstellen
sudo ./backup.sh --to /media/$USER/USBSicherung direkt auf einen USB-Stick schreiben

Regelmäßig eine Sicherung auf USB kopieren — eine Sicherung auf demselben Server hilft nicht, wenn der Server ausfällt. Sicherungen sind nicht verschlüsselt und enthalten alle Passwörter: sicher aufbewahren.

5 Wiederherstellen

sudo ./restore.shvorhandene Sicherungen anzeigen
sudo ./restore.sh --from latest --yesdie neueste Sicherung zurückspielen
sudo ./restore.sh --from /media/$USER/USB/20261031-033000 --yeseine Sicherung vom USB-Stick zurückspielen

Vorher wird der aktuelle Stand automatisch gesichert (pre-restore-…) — eine falsche Wiederherstellung lässt sich rückgängig machen.

6 Update und Rollback

sudo bash task-tracker-onprem-<neu>.runneue Version: erkennt die Installation und bietet das Update an
sudo ./update.sh --rollbackdas letzte Update rückgängig machen
sudo ./update.sh --restartnur neu starten (z. B. nach Änderung der .env)

Jedes Update sichert zuerst alles. Startet die neue Version nicht sauber, läuft automatisch wieder die alte.

7 Wenn etwas nicht klappt

ZertifikatswarnungZertifikat auf dem Gerät noch nicht importiert (Schritt 4) — oder eine andere Adresse geöffnet als bei der Installation angegeben.
Seite nicht erreichbarsudo docker compose ps — alle drei Dienste „running“, app „healthy“. Protokoll: sudo docker compose logs -f app
Link abgelaufen / Passwort vergessensudo ./invite.sh (für andere Benutzer: --user NAME)
„Checksum MISMATCH“Die .run-Datei ist beschädigt — erneut kopieren.
