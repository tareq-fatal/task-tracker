يُثبَّت Docker تلقائيًا (دون إنترنت من داخل الحزمة). لا تغادر البيانات الخادم — لا سحابة.

٢ التثبيت خطوة بخطوة (دون إنترنت)

  1. 1نسخ المجلد

    صِل ذاكرة USB وانسخ المجلد task-tracker-onprem-v1.1.0 إلى الخادم، ثم ادخل إليه:

    cp -r /media/$USER/USB/task-tracker-onprem-v1.1.0 ~/
cd ~/task-tracker-onprem-v1.1.0
  2. 2بدء التثبيت

    أمر واحد. ‏--locale ar تعني العربية (أو de أو en). اختياريًا --host tracker.marine.local و --ip 192.168.1.10 — وإلا يُكتشف عنوان IP تلقائيًا.

    sudo ./install.sh --offline --tls internal --app-name "Coast Shield" --locale ar
  3. 3الانتظار (٣ إلى ٥ دقائق)

    في النهاية يعرض البرنامج العنوان واسم المستخدم ورابط الدعوة ومسار الشهادة وبصمتها. كل ذلك محفوظ أيضًا في /opt/task-tracker/ACCESS.txt (لمدير النظام فقط): sudo cat /opt/task-tracker/ACCESS.txt

  4. 4استيراد الشهادة — مرة واحدة لكل جهاز

    يُصدر الخادم شهادات HTTPS بنفسه. ليثق بها المتصفح، استورد الملف /opt/task-tracker/ca/task-tracker-root-ca.crt (أو نزّله من http://<Server-IP>/ca.crt) وقارن البصمة:

    Windowsانقر نقرًا مزدوجًا على الملف ← تثبيت الشهادة ← الكمبيوتر المحلي ← «وضع كل الشهادات في المخزن التالي» ← جهات إصدار الشهادات الجذر الموثوق بها.
    Androidالإعدادات ← الأمان ← التشفير وبيانات الاعتماد ← تثبيت شهادة ← شهادة CA.
    iPhone/iPadافتح رابط التنزيل في Safari ← الإعدادات ← تثبيت ملف التعريف؛ ثم عام ← حول ← إعدادات الثقة بالشهادات ← تفعيل.
  5. 5فتح رابط الدعوة

    افتح الرابط في المتصفح واختر كلمة مرور — وبهذا تكون مسجّلًا كمستخدم أعلى (Superuser). الرابط صالح لمرة واحدة فقط ولمدة ٧٢ ساعة. انتهت صلاحيته؟ الأمر sudo /opt/task-tracker/invite.sh يُنشئ رابطًا جديدًا.

مع إنترنت ونطاق خاص: --tls domain --domain tasks.company.com (Let's Encrypt). داخل شبكة مغلقة فقط ودون تشفير: --tls http (غير مُوصى به).

٣ الاسم والشعار واللغة

الاسم--app-name "Coast Shield" — يظهر في كل مكان بدلًا من «متتبِّع المهام». في الحزمة دون إنترنت يكون الاسم مدمجًا مسبقًا (اطلب الحزمة بهذا الاسم).
الشعار والألوانداخل التطبيق كمستخدم أعلى: الإعدادات ← الهوية ← رفع الشعار. يُحفظ ضمن النسخ الاحتياطية.
اللغة--locale ar|de|en — لغة صفحة الدخول ولغة المستخدم الأعلى. ويستطيع كل مستخدم تغيير لغته بنفسه.

نفّذ كل الأوامر داخل المجلد /opt/task-tracker: ‏cd /opt/task-tracker

٤ النسخ الاحتياطي

تلقائيًاكل ليلة الساعة 03:30، ويُحتفظ بآخر ١٤ نسخة في /var/backups/task-tracker
sudo ./backup.shإنشاء نسخة احتياطية الآن
sudo ./backup.sh --to /media/$USER/USBكتابة النسخة مباشرة على ذاكرة USB

انسخ نسخة احتياطية إلى ذاكرة USB بانتظام — النسخة الموجودة على الخادم نفسه لا تنفع إذا تعطّل الخادم. تحتوي النسخة على كل كلمات المرور: احفظها في مكان آمن.

٥ الاستعادة

sudo ./restore.shعرض النسخ الاحتياطية المتاحة
sudo ./restore.sh --from latest --yesاستعادة أحدث نسخة
sudo ./restore.sh --from /media/$USER/USB/20261031-033000 --yesاستعادة نسخة من ذاكرة USB

قبل ذلك تُحفظ الحالة الحالية تلقائيًا (pre-restore-…) — لذا يمكن التراجع عن استعادة خاطئة.

٦ التحديث والتراجع

sudo ./update.sh --from /media/$USER/USB/task-tracker-onprem-v1.2.0تثبيت إصدار جديد من ذاكرة USB (دون إنترنت تلقائيًا)
sudo ./update.sh --rollbackالتراجع عن آخر تحديث
sudo ./update.sh --restartإعادة التشغيل فقط (مثلًا بعد تعديل ملف .env)

كل تحديث يبدأ بنسخة احتياطية كاملة. وإذا لم يعمل الإصدار الجديد بشكل سليم، يعود الإصدار القديم تلقائيًا.

٧ إذا لم يعمل شيء ما

تحذير الشهادةلم تُستورد الشهادة على هذا الجهاز بعد (الخطوة ٤) — أو فُتح عنوان غير المحدد في --host/--ip.
الصفحة غير متاحةsudo docker compose ps — يجب أن تكون الخدمات الثلاث running و app بحالة healthy. السجل: sudo docker compose logs -f app
انتهت صلاحية الرابط / نسيت كلمة المرورsudo ./invite.sh (لمستخدم آخر: --user NAME)
